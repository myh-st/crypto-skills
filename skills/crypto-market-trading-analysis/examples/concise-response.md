# Concise response example

Default current-market answers use the Daily Update shape.

~~~text
SUI/USDT — WAIT_FOR_BREAKOUT_CONFIRMATION | Bias: Bullish

Price: $1.18
Key zone: $1.16–1.17 support → $1.20–1.22 resistance
Flow: leverage is elevated; breakout quality depends on real spot confirmation.
Today: WAIT. DCA only after a flush + OI reset + reclaim, or add after a confirmed 4H breakout.
Invalidation: support breaks while OI stays flat/up and spot selling remains strong.
Watch: OI on the next dip and spot volume through resistance.
~~~

For an explicit execution-plan request, a slightly larger answer is allowed:

~~~text
SEI/USDT — WAIT_FOR_PULLBACK

Buy zone: $0.062–$0.067
Invalidation: daily close below $0.048
Targets: $0.084 / $0.096
Horizon: 2–8 weeks

Why:
- HTF structure is constructive but price is extended.
- Funding/OI make chasing unattractive.
- Supply risk lowers breakout quality.
~~~

These are format examples only. Refresh all prices, levels, flows and data-quality notes for every
live analysis.
